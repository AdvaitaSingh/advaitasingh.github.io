# Advaita Singh — academic website

Static site for GitHub Pages. No build dependencies.

1. Sign in to GitHub as `advaitasingh` (if the username is available to you).
2. Create a public repository called `advaitasingh.github.io`.
3. Upload these files directly to its root, not inside a folder.
4. In Settings > Pages, choose Deploy from a branch, main, / (root), then Save.
5. The site will be served at https://advaitasingh.github.io/ after deployment.

The site contains a condensed printable CV rather than the original PDF, which includes a phone number. Review the public email, bio, research titles, and coauthor permissions before publishing. To attach a public CV PDF later, upload it as CV.pdf and add a link to it on cv.html. The photo is intentionally omitted until you supply one.

To preview locally, open index.html in a browser.
